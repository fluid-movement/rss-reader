FTS5 virtual table `items_fts` (title, content text stripped of HTML, external-content on items) kept in sync with triggers, created via a custom Drizzle SQL migration since drizzle-kit does not model virtual tables; verify FTS5 is available in `node:sqlite`. Search joins to feeds for user scoping. Retention: scheduler job once a day deleting items where published/fetched older than N days and no unread/starred state rows for the user; setting stored per user or env default (e.g. 90 days). Delete cascades to FTS via triggers.
