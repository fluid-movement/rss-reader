Pull down on the list to refresh the current view (feed or all) with a clear indicator and a result toast, built on the existing refresh action and cooldown; works in the installed PWA where the browser's native pull to refresh is disabled by the overscroll rules; a visible Refresh button stays available as the accessible alternative; does not fight with scrolling or with the drawer.
