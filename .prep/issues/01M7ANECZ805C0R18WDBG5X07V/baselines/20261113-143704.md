With real feeds, a feed that fails (for example the dead kottke.org URL returning 404) is only visible on /feeds. In the sidebar there is no hint, and the feed's own view just says 'No articles here yet'. Show a small warning indicator on failing feeds in the sidebar (feeds with error_count >= 3, the same threshold the /feeds page uses, with the last error in a tooltip) and, in a failing feed's own list view, show the last error and a Retry button (existing refresh action) above the empty state or the list. Use shadcn components, keep the sidebar clean, and keep counts exact.
